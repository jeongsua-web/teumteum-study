# 틈틈 · 정보처리산업기사 실기

https://jeongsua-web.github.io/teumteum-study/

모바일에서 한 문제씩 학습하는 정적 웹사이트입니다.

- 5개 회차, 96문제와 연결된 개념 설명·예시·기억할 포인트
- 회차별 학습, 랜덤 5문제, 개념·문제 검색
- 참고 답안과 자가 채점, 오답 복습, 북마크
- 답안 초안과 학습 위치를 브라우저에 저장
- 학습 기록 JSON 내보내기·불러오기

참고 답안과 개념 설명은 별도로 작성한 학습 자료이며 공식 정답표가 아닙니다. 원문 확인이 필요한 문제는 별도로 표시합니다. 본문이 없는 4문제는 제외했습니다.

학습 기록은 각 기기·브라우저의 로컬 저장소에 남습니다. 기기를 옮길 때는 기록 내보내기와 불러오기를 사용하세요.

GitHub Pages는 main 브랜치 루트의 정적 파일을 배포합니다. 별도 서버나 빌드 과정이 필요하지 않습니다.
